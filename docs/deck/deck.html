The solution

A director agent with ten engines.
Precise where it matters, generative where it helps.

You ask a question and add notes or PDFs. Gemini writes a storyboard for the ear, beat by beat, and routes each beat to the engine that can show it truthfully. Every beat is rendered to the exact length of its narration, checked, and assembled into a finished video with music and subtitles.

exactMath animation · Globe & maps · Data chart · Timeline · Flow diagram · Whiteboard · Kinetic type
generatedIllustrated shots · Guide character · Veo video

Facts, numbers, maps and math are always drawn by code from real data. Generated pixels never carry a fact.

How it works

From a question to a finished video.
You only make the calls.

01AskYouA question plus optional notes, PDFs or images. Format, length, language, narrator, audience.
02Storyboard + castGemini 3.1 ProNarration beat by beat, an engine per beat, and the recurring cast: style, characters, objects, places.
03NarrateGemini TTSEach line is voiced first, then transcribed and retaken if it drifts from the script.
04Render + self-checkEnginesBeats render in parallel to their exact length. Manim code is repaired on error and inspected by Gemini vision.
05Edit one beatYou + directorRewrite a line, swap an engine, or say "show it on a map". Only that beat re-renders.
06Assemble + translateLyria · ffmpegMusic ducked under the voice, -14 LUFS, subtitles. One-click versions in other languages reuse the visuals.

MitraField7

Gen AI implementation

Not one prompt. Five loops that check each other.

01

Route

The director reads every engine's description and picks per beat, under rules: facts go to exact engines, Veo is capped at two.

02

Code + repair

Gemini writes Manim for the exact duration. Render errors go back with the traceback until it compiles.

03

Look + fix

Gemini vision inspects rendered frames for overlapping or cut-off text and asks for a corrected scene.

04

Listen + retake

Every narration line is transcribed and retaken if words were added, dropped or garbled.

05

Stay on model

Cast references feed every image and Veo first frame, so characters and subjects stay consistent.

Failures degrade gracefully: a refused Veo clip becomes a still, a failed engine becomes a title card, and the video still renders.
